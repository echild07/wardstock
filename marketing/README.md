# Marketing materials

- **`leeward_wardstock_flyer.html`** — LeeWard-branded flyer, up to date as of this file: covers WardStock's features, the two-piece architecture ("At Sea" / "At Harbor" — WardStock vs. the Lucius engine, with the privacy angle: raw data and analytics stay on your own home server, never a shared cloud), and a LeeWard copyright/IP-ownership footer. Uses the transparent-background logo (`leeward_logo_transparent.png`, same folder) embedded directly in the HTML.

- **PDF generation: works, but build on demand, not by default** — `wkhtmltopdf` can render this to PDF (page-size Letter, local font substitutes needed since this environment can't reach Google Fonts at render time — see the `<link>` swap needed for `Liberation Serif/Sans/Mono` in place of `Fraunces/Inter/Space Mono`). **One known rendering bug to remember:** the two-column "At Sea / At Harbor" comparison uses an HTML `<table>` (CSS Grid/Flexbox/floats all failed identically in `wkhtmltopdf`'s old rendering engine — confirmed via isolated testing, not assumed) — and specifically, **`border-radius` on a `<td>` causes this engine to silently collapse the whole table to stacked rows instead of side-by-side columns.** The current file has no `border-radius` on `.harbor-card` for exactly this reason — if that ever gets re-added (e.g. during a redesign), the columns will silently break again in PDF output only (the live HTML in a real browser is unaffected).

Only regenerate the PDF when actually needed — it took real iteration to get right, and the source HTML here is the thing worth keeping current, not a pre-built PDF.
